## Данные (файл `Core.swift` — читайте, не меняйте)
Данные те же, что у веб-версии, лежат на сервере коллекциями записей и синхронизируются сами.
- `JSON` — enum со свободной структурой: `.s(String) .n(Double) .b(Bool) .o([String:JSON]) .a([JSON]) .null`; `v["ключ"]` даёт `JSON?`; у `JSON?` есть `.str` (всегда строка, числа форматирует), `.num: Double?`, `.arr: [JSON]`; у `JSON` ещё `.bool`, `.obj`.
- `Rec(id:, v:)` — запись; `rec["поле"]` = `rec.v["поле"]`.
- `Store` (`@EnvironmentObject var store: Store`): `list("коллекция") -> [Rec]`, `get(c, id)`, `put(c, Rec)` (сохраняет на устройстве сразу и шлёт на сервер), `delete(c, id)`, `kv("ключ") -> JSON?`, `setKV(ключ, JSON)`, `cfg: JSON` (настройки: `cfg["reqSecs"]`, `cfg["shops"]`, `cfg["post"]`, …; изменить настройку: `var c = store.cfg; c["ключ"] = ...; store.setKV("cfg", c)`), `token`, `state`, `pendingCount`, `sync()`.
- Коллекции: `requests, closings, schemes, journal, issues, tasks, notes, expenses, joints, mats, snips, contacts`, плюс `kv` (ключи `name`, `cfg`, …). Структуру записей смотрите в веб-версии (см. ниже), **не выдумывайте поля**: правя запись, берите её копию (`var r = rec; r.v["поле"] = ...`), чтобы не потерять поля, которые знает только веб.
- Новые id: `Fmt.uid()`. Даты в записях — строка `yyyy-MM-dd`: `Fmt.today`, `Fmt.date(s) -> Date?`, `Fmt.show(s)` → `дд.мм.гггг`, `Fmt.iso.string(from:)`, `Fmt.num(Double, знаков)` — число по-русски с пробелами и запятой.
- Файлы чертежей: `FileCache.get(id, token:)`. Адрес сервера: `API.base`.

## Навигация (важно)
Корневые экраны **не содержат `NavigationStack`**: оболочка сама оборачивает каждый раздел в `NavigationStack`. Внутри экрана используйте `NavigationLink(value:)` + `.navigationDestination(for:)`, `.navigationTitle`, `.toolbar`, `.searchable`. Окна создания и правки показывайте через `.sheet`, внутри листа свой `NavigationStack`. Все корневые экраны создаются **без аргументов**: `ИмяView()`.

## Качество (применить навыки)
Сначала вызовите навык `swiftui-pro:swiftui-pro` и следуйте ему; по ситуации `swiftui-patterns`, `apple-design`, `make-interfaces-feel-better`, `liquid-glass-design` (для iOS 16 — материалы `.ultraThinMaterial` вместо iOS 26 API). Требования:
- вид без «шаблонной нейросетевой» манеры: никаких эмодзи вместо иконок, SF Symbols с понятным смыслом, одна система отступов, ровные сетки, числа `monospacedDigit`;
- iPad: широкие экраны не растягивайте на всю ширину — формы и списки в колонке до ~720 pt по центру или в две колонки (`horizontalSizeClass`); iPhone: ничего не обрезается, минимальная цель нажатия 44 pt;
- движение: пружинные отклики на нажатие (`Pressable`), `withAnimation` на добавление и удаление строк, лёгкая тактильная отдача на подтверждениях; уважайте `accessibilityReduceMotion`;
- доступность: подписи `accessibilityLabel` у иконок-кнопок, Dynamic Type не ломает вёрстку;
- пустые состояния через `EmptyNote` с подсказкой, что делать; удаление — свайпом с подтверждением там, где потеря данных ощутима; ввод — правильные клавиатуры (`.decimalPad`, `.numberPad`), кнопка «Готово» над клавиатурой.
